# Юридический консультант по НПА РК

Локальный сервис вопрос-ответ по нормативно-правовым актам (НПА) Республики
Казахстан. Забирает тексты кодексов и законов с ИПС «Әділет»
(adilet.zan.kz), индексирует их и отвечает на вопросы, опираясь только на
эти тексты, со ссылками на конкретные статьи. Умеет также проверять
загруженный договор (.docx/.pdf) на несоответствие корпусу.

Модели работают локально через Ollama — интернет нужен только на этапе
скрейпинга.

## Честные ограничения

- Корпус — это ровно то, что перечислено в `config/sources.yaml` (на момент
  написания — 21 акт). Если акта нет в списке, консультант о нём ничего не
  знает и не должен ничего выдумывать.
- Судебной практики, разъяснений и подзаконных актов, не включённых в
  список, в корпусе нет.
- Сканы и PDF без текстового слоя не распознаются — OCR не реализован,
  такие файлы `docparse` не прочитает.
- Ответы — это справочная информация по текстам законов, а не юридическая
  консультация. Перед принятием решений нужно свериться с первоисточником
  и при необходимости обратиться к юристу.
- Модель может ошибаться. Проверяйте ссылки на статьи, которые приводятся
  в ответе.

## Требования

- Python 3.11
- [Ollama](https://ollama.com) с двумя моделями: `bge-m3` (эмбеддинги) и
  `qwen3:4b-instruct` (генерация)
- GPU с 4 ГБ видеопамяти (индексация и генерация на CPU работают, но
  сильно медленнее — таймингов для CPU нет)
- Свободное место на диске: корпус в `data/raw` и `law.db` — единицы
  гигабайт с учётом векторного индекса

## Установка

```bash
python -m venv .venv
.venv/Scripts/activate            # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium       # нужен скрейперу и браузерным тестам —
                                   # pip install его не ставит
```

Установите модели в Ollama:

```bash
ollama pull bge-m3
ollama pull qwen3:4b-instruct
```

Скопируйте `.env.example` в `.env` и при необходимости поправьте значения:

```bash
cp .env.example .env
```

## Сборка корпуса

```bash
python cli.py scrape          # забрать все акты из config/sources.yaml
python cli.py index           # построить индекс (эмбеддинги + FTS) в law.db
```

- `scrape` идёт через настоящий браузер (Playwright), чтобы пройти
  антибот-проверки adilet — на все 21 акт уходит порядка 10 минут. Можно
  ограничить набор: `python cli.py scrape --only labour_code tax_code`.
  Если акт не грузится (например, признан утратившим силу — скрейпер
  сознательно отказывается его индексировать), команда сообщает об ошибке
  по этому ключу и продолжает остальные.
- `index` требует запущенной Ollama (дергает `bge-m3` для эмбеддингов) и
  может идти несколько часов на слабом GPU — контрольная точка: на GTX
  1650 Ti полная сборка заняла несколько часов и дала порядка 18000
  чанков. Каждый запуск `index` пересобирает и заново эмбеддит все акты
  из `data/raw` целиком (для уже проиндексированного акта старые чанки
  удаляются и считаются заново) — это не инкрементальная дозаписи по
  новым файлам, а полная пересборка.
- `python cli.py status` показывает, что уже в индексе и чего не хватает.

Чтобы добавить или заменить акт, отредактируйте `config/sources.yaml`
(ключ, заголовок, URL на adilet.zan.kz, тип документа) и запустите `scrape`
заново. Скрейпер проверяет, что акт действует на дату загрузки, и
откажется добавить в корпус акт, утративший силу целиком.

## Запуск сервера

```bash
uvicorn app:app --port 8000
```

Откройте `http://localhost:8000` — там форма вопроса к консультанту и
вкладка загрузки договора на проверку.

## Тесты

Обычный прогон (без сети, без Ollama, без браузера):

```bash
python -m pytest -q
```

Часть тестов помечена `@pytest.mark.integration` и по умолчанию не
запускается (см. `pytest.ini`):

- `tests/test_integration.py` — требует запущенной Ollama и уже собранного
  индекса (`python cli.py scrape && python cli.py index`). Без этого тесты
  сами себя пропускают (`pytest.skip`), а не падают.
- `tests/test_ui.py` — требует запущенного сервера
  (`uvicorn app:app --port 8000`) и Playwright/Chromium
  (`playwright install chromium`, см. установку выше).

Запуск интеграционных и браузерных тестов:

```bash
python -m pytest -m integration tests/test_integration.py tests/test_ui.py
```
